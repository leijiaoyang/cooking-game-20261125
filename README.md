Sizzle & Serve — a complete, original cooking game that plays offline in a desktop browser. Run a kitchen shift: take ingredients from the pantry, chop on the board, fry or boil on the stove, plate the dish and serve it before the customer storms out. Six dishes, three difficulties, a recipe book, buy-and-restock ingredients, WebAudio sound effects and music, and best scores saved per dish.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — no install, no build step, no network requests. The game is plain static files under `game/`; screenshots of real gameplay live in `screenshots/`.
